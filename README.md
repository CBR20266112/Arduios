# Arduios

## 브랜치 운영 방식

- `main`: 항상 실행/배포 기준이 되는 안정 버전 유지
- `dev`(또는 `backup`): 기능 개발, 실험, 진행 백업 기록

### 작업 흐름

1. 일상 개발은 `dev`에서 진행
2. 기능 단위로 커밋해서 진행 이력 보관
3. 안정 동작 확인 후 `main`으로 병합
4. 큰 단위 배포 시 태그로 버전 기록

### 저장소 업로드 규칙

- `node_modules`는 커밋하지 않음
- 불필요한 빌드 산출물(`dist`, `build`, `coverage`)은 제외
- `.env` 등 개인/비밀 설정 파일은 제외

이 구조를 유지하면 문제가 생겨도 `main` 기준으로 빠르게 복구할 수 있습니다.
